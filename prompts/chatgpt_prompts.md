### Relação de Prompts Utilizados ###

1. **Consolidação de Dados**  
   _"Por favor, consolide o conteúdo dos 3 arquivos em um arquivo denominado Maganium_Total_Sales."_  

2. **Geração de Relatório de Ranking**  
   _"Com base no arquivo gerado, crie um relatório com o ranking dos modelos mais vendidos por país e plataforma e o valor total vendido daquele modelo."_  

3. **Geração de Arquivo Markdown**  
   _"Por favor, gere um arquivo .md."_  

4. **Ranking por País**  
   _"Agora vamos fazer o mesmo, mas desta vez ranqueando por país, sendo que cada país terá o seu ranking de plataforma e modelo."_  

5. **Totalização por País**  
   _"Por favor, repita o mesmo relatório, mas totalizando as unidades por país."_  

6. **Totalização por Modelo Dentro de Cada País**  
   _"Não o total global de unidades por país, mas o total por modelo por país."_  

7. **Formatação Específica do Relatório**  
   _"Por favor, vamos repetir mais uma vez dessa forma:  
     País:  
         Plataforma:  
              Modelo 1 - unidades - valor  
              Modelo 2 - unidades - valor  
              Modelo 3 - unidades - valor  
     Total de unidades: Modelo 1 - Modelo 2 - Modelo 3"_  

8. **Formatação Final do Relatório**  
   _"Por favor, vamos repetir mais uma vez dessa forma:  
     País:  
         Plataforma 1:  
              Modelo 1 - unidades - valor  
              Modelo 2 - unidades - valor  
              Modelo 3 - unidades - valor  

         Plataforma N:  
              Modelo 1 - unidades - valor  
              Modelo 2 - unidades - valor  
              Modelo 3 - unidades - valor  

     Total de unidades: Modelo 1 - Modelo 2 - Modelo 3"_  

9. **Sugestão de Transporte para Otimização Logística**  
   _"Com base nesse último relatório, por favor, gere uma sugestão de transporte para otimizar a logística de entrega."_  

10. **Geração de Arquivo Markdown para a Sugestão de Transporte**  
   _"Por favor, num arquivo md."_
